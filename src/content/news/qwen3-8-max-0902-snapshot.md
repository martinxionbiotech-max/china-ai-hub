Alibaba shipped the Qwen3.8-Max-0902 snapshot on 2026-09-02, an upgraded snapshot of the Qwen3.8-Max API flagship (alias qwen3.8-max-2026-09-02). The vendor describes it as breaking new ground in coding — engineering-scale projects and long-horizon autonomous development — with significantly enhanced collaborative agent performance in multi-tool orchestration, and refined native vision across chart reasoning, document parsing and multimodal perception.

List price is unchanged at $2 input / $6 output per 1M tokens (implicit cache $0.25). Context is 1M tokens (991K max input) with 131K max output and 262K max reasoning. The snapshot retains thinking mode and the full tool ecosystem: function calling, structured outputs, batches and web search.

Note: the database records Qwen3.8-Max benchmark scores from the vendor model card for the open Qwen3.8-2.4T-A95B weights, which are text-only and thinking-only — not the same product as the API flagship with vision and video input.
